# QR Bio Pages Repository

This repository hosts personal Linktree-style bio pages for various customers, optimized for fast loading and QR code scanning via **GitHub Pages**.

## Features included per Bio Page

- **Lightning Fast Performance**: Zero bulky framework dependencies, inlined crisp SVGs, and sub-300ms paint time.
- **Mobile-First UX**: Responsive glassmorphism interface designed for immediate viewing upon camera QR scan.
- **1-Tap Save Contact (`.vcf`)**: Instant download of the client contact card directly into phone address books (iOS & Android compatible).
- **Direct Action Quick Bar**: 1-tap Call, WhatsApp, Email, and Google Maps Navigation.
- **Native Share Support**: Uses native mobile share sheet with automatic clipboard copy fallback.
- **Bilingual & Multi-script Support**: Styled with Google Fonts (`Noto Sans Tamil` & `Plus Jakarta Sans`).
